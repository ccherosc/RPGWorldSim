# Vision

## Core Concept

The AI RPG Simulator is a persistent autonomous medieval world.

The world does not exist for the player. The player exists inside the world.

Citizens should continue to:
- wake,
- sleep,
- work,
- eat,
- socialize,
- worship,
- trade,
- travel,
- marry,
- have children,
- age,
- become injured or sick,
- recover,
- steal,
- lie,
- fight,
- cooperate,
- feud,
- inherit,
- migrate,
- lead,
- rebel,
- die,
- and leave consequences behind,

whether or not the player is nearby.

The goal is to create a miniature society whose stories emerge from simulation rather than authored quest scripts.

## Long-Term Target

The mature simulation should support:
- Five towns with distinct local economies and identities.
- Two castles controlled by neighboring rulers.
- Approximately 1,000 persistent NPCs.
- Multi-generational population continuity.
- Families and households.
- Feudal, civic, religious, commercial, and criminal institutions.
- Agriculture and food production.
- Wildlife, livestock, crops, forests, water, terrain, and weather.
- A persistent economy.
- Local and interregional trade.
- Resource scarcity and transportation.
- Theft and law enforcement.
- Conflict, warfare, raids, invasion, and political succession.
- Religion and communal rituals.
- Disease, injury, disability, and mortality.
- Thousands of persistent world objects.
- Emergent rumors, reputation, gossip, memory, and historical narratives.
- A controllable hero who must obey the same physical world rules.

## What Makes the Project Special

The defining feature is not merely that NPCs can talk using AI.

The defining feature is that each NPC is:
- persistent,
- individually modeled,
- socially connected,
- physically located,
- economically constrained,
- psychologically differentiated,
- historically situated,
- and able to make autonomous decisions that produce lasting consequences.

AI should enrich human-like reasoning and expression while the deterministic simulation remains the authority over reality.

## Observer Experience

The simulation must be entertaining without player intervention.

A user should be able to:
- run time at multiple speeds,
- watch event streams,
- discover developing stories,
- inspect individuals,
- inspect households,
- inspect occupations and businesses,
- inspect inventories,
- inspect relationships,
- inspect memories,
- inspect crime,
- inspect health,
- inspect the economy,
- inspect local politics,
- inspect historical events,
- and ask "Why is this happening?"

A core success metric is:

> Can a user watch this simulation for an extended period with zero input and remain interested in the lives and events that emerge?

## Player Experience

The hero is not a privileged simulation exception.

The hero should eventually:
- live in the same geography,
- travel through the same roads,
- consume the same food,
- buy and own real objects,
- experience the same weather,
- be remembered by NPCs,
- gain or lose reputation,
- participate in the economy,
- become part of relationships and political systems,
- and alter a history that was already unfolding before arrival.

The player should enter a living system rather than trigger a static narrative.
